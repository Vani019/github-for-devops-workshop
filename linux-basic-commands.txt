## 🔹 BASIC LINUX COMMANDS

### 1️⃣ `pwd`

**Print Working Directory**
Shows your current location.

```bash
pwd
```

👉 Output example:

```
/home/ubuntu/kubernetes-project
```

---

### 2️⃣ `ls`

Lists files and folders.

```bash
ls
```

Common options:

```bash
ls -l    # long details (permissions, size)
ls -a    # show hidden files
ls -lh   # human readable size
```

---

### 3️⃣ `cd`

Change directory.

```bash
cd folder_name
cd ..
cd ~
```

* `cd ..` → go one step back
* `cd ~` → go to home directory

---

### 4️⃣ `mkdir`

Create a directory.

```bash
mkdir test
```

Create nested folders:

```bash
mkdir -p app/logs/nginx
```

---

### 5️⃣ `rmdir`

Remove empty directory.

```bash
rmdir test
```

---

## 🔹 FILE COMMANDS

### 6️⃣ `touch`

Create empty file.

```bash
touch file.txt
```

---

### 7️⃣ `cat`

Show file content.

```bash
cat file.txt
```

---

### 8️⃣ `less`

View large file safely.

```bash
less file.txt
```

* Press `q` to quit

---

### 9️⃣ `cp`

Copy files or folders.

```bash
cp file1 file2
cp -r folder1 folder2
```

---

### 🔟 `mv`

Move or rename files.

```bash
mv old.txt new.txt
mv file.txt /tmp/
```

---

### 1️⃣1️⃣ `rm`

Delete files or folders.

```bash
rm file.txt
rm -r folder
rm -rf folder
```

⚠️ `rm -rf` is dangerous → deletes permanently.
